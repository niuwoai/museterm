## 修复行为

SSH 进程确认结束后，等待已接收的输出完成解析，再恢复普通屏幕及终端交互模式，最后显示诊断、断连或重连提示。保留普通屏幕内容和滚动历史；后台仍运行时，查看器断开不会触发终端恢复。

恢复涵盖备用屏幕 47/1047/1049、正常屏幕光标、字符集、键盘模式、鼠标与焦点报告、粘贴模式、插入模式和默认备用屏幕滚轮行为。丢弃未完成的控制序列时不触发其完成处理，也不向后台发送输入。本地诊断引用中的控制字符显示为转义文本。

## 覆盖边界与历史记录

公开文字报告中的本机用户名、主机名和个人绝对路径已脱敏；历史脚本中的 `$WORKSPACE` 表示仓库根目录。截图包含本机标识，仅留本地并由本目录 `.gitignore` 排除。构建日志和 `.xcresult` 也仅保存在本地，报告保留其相对路径供复查。

实际 QA App 使用独立应用标识、测试目录和私有 Runtime，验证启动、创建标签、持有控制租约的输入、屏幕回读、释放租约及关闭标签。普通 shell 的 GUI 截图只证明这些交互；SSH 退出恢复由原生回归覆盖，未在用户远程主机或已安装应用上执行验收。

[早期完整回归失败记录](unit-initial-failure.md) 保留两轮各 1 项 `input_echo_changed` 超时及原始 `.xcresult` 路径，分别发生在保存失败和初始 PTY 尺寸测试。两个用例改用已有的固定回显 shell 夹具并等待就绪标记，保留原有保存失败后的输入断言和真实尺寸断言，产品校验保持不变。

`native-gui/` 保留早期 AppleScript 冒烟失败记录：直接输入未持有 Runtime 控制租约，受到安全校验拒绝。后续驱动改为通过现有 Runtime API 取得自己的控制租约，不放松产品的输入校验。测试驱动早期的输入模式假设及关闭标签语法问题也在隔离驱动中修正。

若截断回放已丢失备用屏幕入口，普通屏幕中的内容来源无法可靠判定，恢复选择保留这些内容，避免误删历史。未宣称覆盖终端实现的全部扩展协议。

## 重现原生回归

在本工作区运行：

```bash
ruby scripts/ssh_terminal_cleanup_test_report.rb
```

可以传入 `musetermTests/测试类[/测试方法]` 缩小范围。驱动使用独立应用标识与构建目录，输出 JSON、Markdown、完整构建日志和逐次保留的 `.xcresult`；不会替换已安装应用。需要复用本机已有依赖 checkout 时，可设置 `MUSETERM_TEST_SOURCE_PACKAGES`。

完整回归退出测试宿主后，在有桌面会话的 macOS 上运行实际 App 驱动：

```bash
ruby scripts/ssh_terminal_cleanup_app_smoke.rb
```

它仅接受上述回归构建的 QA 应用标识，使用自己的临时目录、私有后台及控制租约，关闭自己创建的标签和进程，输出 JSON、Markdown，并尽可能截取自己的应用窗口。不要与同一 QA 应用标识的 Xcode 测试并行运行。
