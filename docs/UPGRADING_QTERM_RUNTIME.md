# 升级与终端会话保留

1.251.0-rc31 / Build 346 新建终端默认由独立后台持有。正常退出或重开界面不会关闭这些终端；明确关闭标签、分屏或终端才结束相应进程。保存恢复记录失败时取消退出，保留当前查看器。

## 从旧版升级

1.250.0-rc1 等旧版由界面进程直接持有 PTY，没有可用的热迁移协议。不能先退出旧版再声称原终端进程保持。

需要保留当前运行会话时，只更新磁盘上的应用，保留旧 QTerm 进程和窗口继续运行。旧窗口仍使用旧版代码，独立后台能力在下一次启动新版后生效。等待当前终端任务结束，再自行关闭旧版并启动新版。安装替换不会清理配置、Profile、快捷命令或历史数据。

## 已使用独立后台后的升级

新版查看器连接兼容的原后台，不为对齐版本而强制重启服务。缺少原进程时显示错误，不静默创建替代 shell 冒充恢复。后台自身崩溃、系统重启及旧 LocalProcess 会话不承诺保留原进程。

QTerm 终端后台与 WillDeep Runtime 职责独立。更新 QTerm 或 WillDeep CLI 不要求执行 daemon upgrade；要保持正常 Runtime 时，不应调用该命令或重启该进程。原生状态接入需要包含 QTerm 协议支持的 WillDeep CLI。
