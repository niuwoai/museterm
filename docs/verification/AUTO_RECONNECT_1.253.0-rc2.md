# 终端自动重连

版本：1.253.0-rc2 / Build 352；日期：2026-10-26。

## 行为

- 输出订阅出现连接不可用或超时后，以 0.25、1、3 秒间隔最多重试三次；重试期间不显示断线横幅，耗尽后显示原有手动重连入口。
- 只有持续收到并确认输出或心跳至少 30 秒后，后续断线才能重置重试预算；等待超时的时间不算健康时间。
- 只订阅已有会话，校验后台 epoch 和会话 generation，从已确认的输出游标继续；迟到的渲染确认与重连输出重叠时裁掉重复字节。
- 不重发输入，不创建替代 shell，不重启终端后台或 WillDeep Runtime。关闭查看器会取消待执行重试。
- 身份、能力、协议、帧格式等不可恢复错误立即提示，不盲目重试。首次创建会话失败和不确定的输入写入失败仍走原有错误处理。

## 验证

- 首轮三项专项测试通过：退避预算与不可恢复错误、真实后台断开订阅后原 PTY 恢复、连续断开耗尽后手动恢复。
- 最终完整单测 666/666 通过，结果包 `/private/tmp/qterm-reconnect-all-b.xcresult`；新增五项覆盖重连、耗尽、取消、预算和输出去重。测试使用私有后台和自有 PTY，未向用户终端注入断线或测试输入。
